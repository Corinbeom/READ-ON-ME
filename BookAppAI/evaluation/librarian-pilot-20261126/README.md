## 데이터와 검색 로직의 효과

같은 질문을 ① 기존 125권 ② 책만 추가한 141권 ③ 같은 141권에서 검색 의도 분류를 수정한 뒤 각각 한 차례 실행했다. 질문과 적합 기준은 첫 검색 전에 고정했다. 독자 질문 8개의 첫 책 적합은 **0/8 → 6/8 → 8/8**이었다. 가상 작가·수상명 질문은 각 단계에서 두 건 모두 빈 결과였다. 8문항은 이번 책으로 답할 수 있는 질문으로 골랐으므로 갈피 전체의 적중률로 일반화할 수 없다. [질문과 판정 기준](questions.json) · [단계별 검색 결과](evaluation.json)

| 질문에서 요청한 내용 | 기존 125권 첫 결과 | 책 추가 후 | 분류 수정 후 |
|---|---|---|---|
| 사과하는 법을 다룬 그림책 | 무영이가 사라졌다 | 무영이가 사라졌다 | 사과는 이렇게 하는 거야 |
| 식물도 움직이는지 아이와 읽기 | 나인 | 식물도 움직여? | 식물도 움직여? |
| 갯벌에 가기 전 생물 알아보기 | 빈 결과 | 찾았다! 갯벌 친구들 | 찾았다! 갯벌 친구들 |
| 띄어쓰기를 그림과 이야기로 익히기 | 빈 결과 | 왜 띄어 써야 돼? | 왜 띄어 써야 돼? |
| 학교 신문 동아리 동화 | 빈 결과 | 내가 진짜 기자야 | 내가 진짜 기자야 |

| 수의사가 일하는 현장 | 빈 결과 | (유쾌한 수의사의)동물병원 24시 | (유쾌한 수의사의)동물병원 24시 |
| 고등학생이 처음 읽는 철학 | 빈 결과 | 자기만의 철학 | 자기만의 철학 |

『무영이가 사라졌다』는 친구가 사과하는 초등 동화지만, 유아와 볼 사과 그림책이라는 조건을 소개에서 확인할 수 없어 부적합으로 판정했다. 『나인』은 식물의 소리를 듣는 청소년 소설이다. 두 책 모두 주제어 일부가 맞아도 독자가 찾는 형식과 내용이 달랐다.

분류 수정 전 두 실패 질문 모두 “이야기하고 싶어요”의 “이야기” 때문에 서사 도서만 남겼다. 사과 그림책은 교육 도서로, 산수화 책은 비문학으로 태깅돼 상위 후보 10권에도 들어가지 못했다. 이제 독자가 서로 대화하고 싶다고 말하는 표현은 도서 형식 판단에서 제외한다. 같은 질문에 “소설” 등 별도의 서사 요청이 있으면 이를 유지한다.

기존 고정 질문 20개와 독자 상황 30개의 형식 판정을 전후 대조했다. 바뀐 기존 질문은 “장애가 있는 사람이 자기 일상을 직접 쓴 책을 읽고 수업에서 이야기하고 싶어요” 한 건으로, 서사만 허용하던 제한이 풀렸다.

기존 독자 상황 30개 중 별도 4개로 책 추가 전후를 비교했다. 천문, 기후 토론, 첫 월급 세 질문은 두 번 모두 적합한 첫 책이 나왔고, 한글을 막 배운 아이가 읽을 한국 동물 그림책 질문은 두 번 모두 빈 결과였다. 천문·기후 질문의 첫 책은 영어 판본이다. [별도 대조 질문](holdout.json)

## 다음 묶음을 만드는 방법

검증 DB를 대상으로 BookAppAI 디렉터리에서 다음 명령으로 이번 파일을 재현할 수 있다. 다른 묶음은 조사표에서 선정한 ISBN을 마지막 인자로 넘기면 된다. 원자료가 갱신되면 새 조사표와 발췌 검토가 필요하다.

```sh
pilot=evaluation/librarian-pilot-20261126
python "$pilot/prepare_fields.py" /path/to/recommendations.csv $(jq -r '.[] | select(.field=="title") | .isbn' "$pilot/fields.json") > rebuilt.json
cmp rebuilt.json "$pilot/fields.json"
python -m tools.reviewed_corpus import rebuilt.json --new-only
python -m tools.reviewed_corpus index $(jq -r '.[] | select(.field=="title") | .isbn' rebuilt.json)
```

새 판본의 48개 필드, 16권의 태그와 벡터, 기존 125권의 필드 이력·태그·벡터 일치를 확인했다. 별도로 확보한 성인 35권은 [성인 자료 조사 및 등록용 필드](adult-sources.md)에 정리했다.

## 141권 검증 DB의 공개 기준 평가

같은 141권으로 고정 질문 18개와 가상 작가·수상명 2개를 두 차례 실행했다. 적합 판정은 각 질문의 기존 기준과 ISBN을 사용했다. 두 번 모두 공개 기준을 통과했다. [질문별 추천 순서와 적합 판정](evaluation.json)

| 지표 | 통과 기준 | 1차 | 2차 |
|---|---:|---:|---:|
| 첫 책 적합 | 13/18 | 18/18 | 17/18 |
| 적합한 책 한 권 이상 | 15/18 | 18/18 | 18/18 |
| 가상 질문에 정상 빈 결과 | 2/2 | 2/2 | 2/2 |

2차에서 “어두운 분위기의 책”의 첫 책은 『파과』였다. 추천 근거만으로 독자가 요청한 분위기를 확인하기 어려워 첫 책 점수를 주지 않았다. 별도 사용자 사례인 “번아웃 올 때 읽을 만한 책”에서는 두 번 모두 『내가 뭘 했다고 번아웃일까요』가 첫 책이었다.

로컬 검색 API에서도 사과 그림책, 초등 산수화, 장애 당사자의 일상에 관한 세 질문을 다시 실행했다. 첫 책은 각각 『사과는 이렇게 하는 거야』, 『옛 그림속 자연』, 『실격당한 자들을 위한 변론』이었다. 세 응답 모두 HTTP 200이었고, 반환된 네 건은 상세 API의 제목·소개와 일치했다. 사과 질문의 두 번째 책은 여전히 연령과 형식이 맞지 않는 『무영이가 사라졌다』였다. AI 서버 자동 테스트는 239개가 통과했다. 이번 측정과 색인은 로컬 검증 DB에서 진행했다.
