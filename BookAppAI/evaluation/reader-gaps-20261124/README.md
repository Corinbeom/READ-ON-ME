# 갈피에서 답을 찾지 못했던 여섯 가지 독서 질문

운영판과 자료·코드 지문이 같은 113권을 기준으로 검증 DB에 8권을 추가했다. 7권은 [지난번 후보](../acquisition-20261123/candidates.json) 30권에서 골랐고, 1권은 같은 충남도서관 소장목록에서 보완했다. 기준 질문의 문장, 검색 코드, 모델 설정은 전후에 동일하게 유지했다.

| 독서 상황 | 추가한 책 | 판본에서 확인한 내용 |
|---|---|---|
| 달리기를 시작하고 싶다 | 『오늘부터 달리기를 합니다』, 『나는 달리기가 싫어』 | 첫 책은 걷기부터 시작하는 4주 훈련서, 둘째는 걷기를 섞으며 습관을 만드는 러닝 에세이다. |
| 아이와 갈등이 생길 때 어떤 말을 건넬지 알고 싶다 | 『엄마와 아이 사이 아들러식 대화법』, 『내 아이 고집 이기는 대화법』 | 생활 속 대화 예시와 식사·취침 때 반복되는 실랑이를 다룬다. |
| 큰 글씨로 스마트폰 사진 촬영과 전송을 배우고 싶다 | 『누구나 알기 쉽게 배우는 스마트폰 책』 | 인쇄 본문 14포인트, A4 판형, 갤럭시 카메라와 카카오톡 채팅방 사진 전송 항목을 확인했다. |
| 작은 집의 수납 사례를 사진으로 보고 싶다 | 『1일 5분 정리 수납 정돈법』 | 원룸 거주 가족을 포함한 다섯 가정의 수납 사례와 사진이 있다. |

| 한국으로 이주한 당사자의 목소리를 읽고 싶다 | 『내 이름은 욤비』 | 욤비 토나의 구술을 바탕으로 박진숙과 공동 집필한 책이다. 기존 후보였던 『나는 메리암 디비나그라시아 마뉴엘이다』는 연구소가 엮은 인터뷰집이라 이 질문에는 공동 저자로 확인되는 판본을 추가했다. |

## 자료와 이용 범위

제목·저자·ISBN은 이용허락범위 제한 없음으로 개방된 충남도서관 소장목록에서 등록번호로 확인했다. 소개 8편은 해당 판본의 목차, 판형, 저자 역할 등 확인한 사실을 바탕으로 이 작업에서 한국어로 직접 작성했다. 출판사·서점의 소개문이나 목차 원문은 색인 입력에 포함하지 않았다. [서지 원자료](https://www.data.go.kr/data/15119625/fileData.do) · [각 판본의 서지와 사실 확인 자료](editions.json) · [실제 입력 필드](fields.json)

113권을 복제한 검증 DB에서 [서지 필드 정책](policies.sql)을 적용한 뒤 기존 편집 소개 정책과 함께 사용했다. 등록과 재검증에는 BookAppAI 디렉터리에서 다음 명령을 쓸 수 있다.

```sh
python -m tools.reviewed_corpus import evaluation/reader-gaps-20261124/fields.json --new-only
python -m tools.reviewed_corpus index $(jq -r '.[].isbn' evaluation/reader-gaps-20261124/editions.json)
python -m tools.evaluate_reviewed --reader-scenarios results.jsonl
```

이번 비교에는 기존 30문항 중 9·16·19·20·25·30번을 사용했다. 위 재검증 명령은 전체 30문항을 실행한다.

두 번 모두 러닝은 『오늘부터 달리기를 합니다』, 스마트폰은 『누구나 알기 쉽게 배우는 스마트폰 책』, 수납은 『1일 5분 정리 수납 정돈법』, 전세 계약은 『전세금을 지켜라』, 이주 경험은 『내 이름은 욤비』가 첫 번째였다. 이번에 보강한 여섯 질문에 한정한 결과다. [질문 원문과 네 차례의 추천 목록](evaluation.json)

가족 대화 질문에는 1차에서 『무영이가 사라졌다』가 나왔고 2차에서는 결과가 비었다. 같은 질문으로 후보 목록을 별도 확인하자 『내 아이 고집 이기는 대화법』과 『엄마와 아이 사이 아들러식 대화법』이 최종 순위를 정하기 전 1·2위였다. 이 질문의 후속 점검 대상은 최종 추천 단계다.

## 대화 예시 요청 수정 후 재검증

121권에서 가족 대화 질문을 재현하자 Gemini는 두 양육서를 모두 입력으로 받고도 빈 배열을 반환했다. 같은 질문으로 요청 형식만 실용서로 지정하자, 실용서 후보와 지시를 받은 Gemini가 『엄마와 아이 사이 아들러식 대화법』을 선택했다. 이후 검색 의도 분류기에 ‘대화 예시’와 ‘대화 사례’를 추가했다. 기존 독자 질문 30개와 고정 평가 질문 20개에서 형식 분류가 바뀐 질문은 독자 질문 16번 한 개였다.

| 실행 | 가족 대화 질문에서 처음 추천한 책 | 이 책을 고른 모델 | 여섯 질문 중 첫 책 적합 |
|---|---|---|---|
| 1차 | 『내 아이 고집 이기는 대화법』 | Groq (Gemini 503 이후) | 6/6 |
| 2차 | 『엄마와 아이 사이 아들러식 대화법』 | Gemini | 6/6 |

전세 질문 1차와 이주 질문 1·2차는 모델 장애로 검색 후보 순서를 사용했다. 별도 대조에서 가상 작가·수상명 질문은 모두 빈 결과였다. 이 비교는 여섯 질문의 기능 검증이며 운영 공개를 위한 전체 품질 평가는 별도로 진행한다.
