# 후보 선별 개선 후 임베딩 A/B 평가 — 2026-11-12

## 변경과 범위

검색 의도에 잡힌 `한국` 제약을 소설·SF 등 서사 장르의 후보 필터까지 전달했다. 한국 출처 근거는 코퍼스의 `한국`·`한국소설`·`국내소설` 레이블 또는 소개의 명시적 한국 작가·한국 문학 표현으로만 판단한다. 저자 이름의 한글 표기나 국내 출판사만으로 국적을 추정하지 않는다. `STORY` 요청에는 필사책·시집·명시적 에세이·문학 연구서·장르 안내서와 서사 근거 없는 미분류 논픽션을 제외한다. 그림책·동화·회고록과 서사 레이블이 있는 책은 계속 허용한다. 명시적 `PRACTICAL` 요청에는 서사로 확인된 책을 제외한다.

같은 [이전 파일럿](gemini_embedding_pilot_2026-11-12.md)의 **179권·10개 질의·동일 표본 해시**를 사용했다. 저장한 Gemini 임베딩 벡터를 재사용했으며 이번 후보 비교에서 새 임베딩 API 호출은 없었다. 운영 코퍼스와 임베딩 모델은 변경하지 않았다. 두 방식 모두 동일한 수정 후보 필터와 동일한 Gemini 재정렬 모델을 사용했다.

변경 후 한쪽에만 등장한 44건의 수동 판정은 다음과 같다. ISBN별 판정 근거는 [판정 파일](search_candidate_constraints_ab_labels_2026-11-12.json), 입력 후보는 [후보 기록](search_candidate_constraints_ab_candidates_2026-11-12.json)에 있다. 재집계: `cd BookAppAI && .venv/bin/python -m tools.score_embedding_pilot --results evaluation/search_candidate_constraints_ab_candidates_2026-11-12.json --labels evaluation/search_candidate_constraints_ab_labels_2026-11-12.json`.

| 변경 후 고유 후보 | 부적합 | 애매함 | 적합 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 기존 임베딩 | 3 | 13 | 3 | 19 |

`따뜻한 이야기를 읽고 싶어`에서 두 방식의 필사책·철학 입문서·에세이·시집·장르 해설서가 후보에서 빠졌다. 그림책 『수박 수영장』과 실제 소설은 유지됐다. `어두운 분위기의 책`에서 Gemini 후보의 『SF 소설 읽기』·『다크 심리학 2』가 빠졌다. `한국소설 추천`에서는 Gemini 후보의 번역 SF 소설집 『당신 인생의 이야기』가 빠졌다.

**회수율 손실:** 『날씨가 좋으면 찾아가겠어요』와 『베스트셀러 소』처럼 소설로 확인되는 책도 저장된 국적 근거가 없어 제외됐다. 대신 학교용 한국 소설 선집이 후보 끝에 들어왔다. 현재 코퍼스에는 검증된 저자·작품 출처 필드가 없고 `한국` 태그도 AI 분류 결과일 수 있다. 따라서 이 제약은 완전한 국적 검증이 아니며, 관련 메타데이터 보강 전에는 `한국소설` 결과를 품질 완료로 볼 수 없다.

## 최종 추천 단계

대표 질의 5개에서 두 후보 목록을 같은 Gemini 재정렬 모델에 각각 입력했다. [선택 결과](search_candidate_constraints_final_ab_2026-11-12.json)의 정상 응답만 아래에 집계했다.

| 질의 | 기존 임베딩 후보에서 선택 | Gemini 임베딩 후보에서 선택 |
| --- | ---: | ---: |
| 따뜻한 이야기 | 2 | 1 |
| 어두운 분위기 | 4 | 5 |
| SF 소설 | 5 | 5 |
| 감성적인 에세이 | 2 | 4 |
| 한국소설 | 4 | 4 |

수량은 적합도를 의미하지 않는다. 따뜻한 이야기에서는 기존 후보에서 『재인, 재욱, 재훈』·『베스트셀러 소』, Gemini 후보에서 『베스트셀러 소』가 선택됐다. SF에서는 Gemini 후보 쪽에 『당신 인생의 이야기』·『프로젝트 헤일메리』·『화씨 451』이 포함됐다. 한국소설 재시도에서는 양쪽 모두 한국 작품 네 권이 선택됐다.

첫 한국소설 두 호출과 최종 필터 확인 중 따뜻한 이야기의 기존 후보 호출은 Gemini API **HTTP 503**으로 대체 결과가 나왔다. 해당 호출을 다시 수행해 정상 응답을 얻었다. 따라서 표는 서로 다른 시점의 독립 호출을 합친 탐색 결과다. 모델 출력 변동과 일시 오류를 포함한 반복 실험은 하지 않았다.

## 판단

후보 단계에서는 Gemini 임베딩이 적합한 고유 책을 더 많이 찾는 신호가 있었고, 개선된 형식 필터는 명백한 비서사 후보를 줄였다. 하지만 **이 표본만으로 임베딩 전환을 결정하지 않는다.** 두 방식의 입력 후보 수가 다르고, 표본은 기존 임베딩 상위권을 포함하며, 판정자는 한 명이다. 최종 추천 5개 질의 역시 한 번의 생성 결과와 재시도를 섞은 탐색 평가다. 한국소설의 회수율 손실, 국적 레이블의 출처 신뢰성, API 503 대응을 해결한 뒤 더 넓은 표본으로 재평가해야 한다.
