# 로컬 임베딩과 Gemini API 소규모 비교 — 2026-11-12

## 범위

운영 검색과 `book_corpus`는 변경하지 않았다. `ACTIVE` 17권 전체, 대표 질의 10개에서 기존 임베딩 상위 12권의 합집합, 고정 해시로 선택한 나머지 80권을 합쳐 **179권**을 평가했다. 소개가 30자 미만인 책은 제외했다. [`representative_queries.json`](representative_queries.json)의 12개 질의 중 저자 직접·작가 유사 질의 2개는 참조 벡터 처리 방식이 달라 이번 비교에서 제외했다.

기존 쪽은 DB에 저장된 `jhgan/ko-sroberta-multitask` 도서 벡터와 현재 질의 프롬프트의 새 벡터를 사용했다. Gemini 쪽은 **같은 책의 제목·저자·소개**를 `build_book_text`로 구성해 `gemini-embedding-001`의 `RETRIEVAL_DOCUMENT`, 같은 질의 프롬프트를 `RETRIEVAL_QUERY`로 보냈다. 둘 다 768차원이며 Gemini 응답은 정규화했다. 저장된 기존 벡터 중 `ACTIVE` 5권과 `LEGACY` 10권을 같은 텍스트로 다시 생성해 코사인 유사도 1.0을 확인했다. [Gemini 임베딩 작업 유형과 차원](https://ai.google.dev/gemini-api/docs/embeddings)

같은 179권 안에서 실제 검색 코드의 벡터 상위 30권·태그 상위 20권·검토 승인 장르 경로·제목 경로를 모사하고, **기존 검색·필터·Gemini 입력 후보 선택 함수**를 실행했다. Gemini 재정렬 API와 최종 추천은 실행하지 않았다. 벡터는 `/tmp/readonme-gemini-embedding-pilot-vectors.json`, 결과는 `/tmp/readonme-gemini-embedding-pilot-results.json`에 있으며 Git에는 포함하지 않는다. 재실행 명령은 `cd BookAppAI && .venv/bin/python -m tools.pilot_gemini_embeddings`이다. 기존 모델과 Gemini용 벡터는 서로 다른 공간에서 각각 비교했다.

## 결과

- Gemini 임베딩 **189건(도서 179, 질의 10)**이 성공했고 최종 실패는 없었다. 중간 재시도 횟수는 기록하지 않았다. API 호출 지연 중앙값은 **537ms**, 95백분위는 **635ms**였다. 입력 텍스트 총량은 **49,589자**다. 임베딩 API 응답에 사용 토큰 수가 없어 이 값으로 실제 요금을 확정할 수는 없다.
- 로컬 모델을 새 프로세스에 올리는 데 **약 6.3초**, 이미 올린 뒤 질의 임베딩 10건의 지연 중앙값은 **96ms**였다. 두 지연값은 같은 Mac에서 측정했지만 로컬 모델과 외부 API의 실행 환경이 다르므로 배포 지연의 보증치는 아니다.
- 10개 질의의 Gemini 입력 후보 교집합은 **64권**이었다(기존 입력 총 90건, Gemini 입력 총 98건; 질의 간 중복 포함). SF 질의는 **9/10**, `따뜻한 이야기를 읽고 싶어`는 **2/10**이 겹쳤다.
- `ACTIVE` 도서가 Gemini 입력에 든 횟수는 기존 **13건**, Gemini **16건**이었다. 이 수치만으로 관련성이 높아졌다고 볼 수 없다.

| 질의 | 책 소개로 확인한 차이 |

## 판단과 한계

**API 호출과 768차원 벡터 생성은 가능**했고, 이 작은 표본에서 Gemini가 기존 모델보다 일관되게 낫거나 나쁘다는 결론은 나오지 않았다. API 도입 시 임베딩 호출만큼 검색 경로가 길어질 수 있고, 429·장애 때의 대체 경로가 필요하다. 모델을 고르기 전에는 후보 합집합에 `적합/애매함/부적합` 판정을 붙여 질의별로 비교해야 한다. 특히 이야기·에세이 형식 필터와 `한국소설` 제약의 기존 오류를 모델 차이와 분리해야 한다.

이번 표본은 기존 모델의 상위 후보를 포함해 **기존 모델에 유리하게 구성**됐고, 전체 973권 검색 결과를 대표하지 않는다. 저자 유사 검색, Gemini 재정렬 후 최종 추천, 동시 요청·비용·실제 배포 메모리 절감은 평가하지 않았다. 따라서 이 결과만으로 운영 모델을 전환하지 않는다.
