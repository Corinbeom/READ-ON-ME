# 한국소설 조건 KDC 근거 검증 (2026-11-12)

## 범위

- 로컬 검색 가능 코퍼스 973권에서 기존 형식·장르 필터를 통과한 소설 후보 247권을 조사했다.
- 정보나루 ISBN 상세의 ISBN 일치 레코드에서 KDC를 가져왔다. 책 임베딩이나 Gemini 생성 API는 호출하지 않았다.
- 이 수치는 해당 로컬 DB와 당시 코퍼스의 오프라인 후보 필터 결과이며, 사용자 추천 전체의 품질 지표는 아니다.

## 결과

| 항목 | 권수 |
| --- | ---: |
| KDC `813` 계열 | 112 |
| 다른 `8xx` 문학 번호 | 61 |
| 그 외 KDC | 19 |
| KDC 없음(재조회 후) | 55 |
| 기존 한국소설 조건 통과 | 43 |
| 변경 후 한국소설 조건 통과 | 113 |
| 새로 포함 / 제외 | 78 / 8 |

기존에 빠졌던 『날씨가 좋으면 찾아가겠어요』(`813.7`), 『베스트셀러 소』(`813.7`), 『소년이 온다』(`813.62`)가 포함됐다. 반대로 『파친코 1』(`843.6`), 『작은 땅의 야수들』(`843.6`), 『백조와 박쥐』(`833.6`)는 기존 한국 관련 태그·소개가 있어도 제외됐다.

저장된 `한국소설 추천` Gemini 질의 벡터를 사용해 DB 검색 단계도 오프라인으로 확인했다. 상위 검색 후보 30권에서 한국소설 조건 통과 수는 10권에서 12권으로 늘었다. 이 실험은 질의 벡터 재생과 후보 필터까지만 확인했으며, LLM 재정렬·추천 이유 생성은 실행하지 않았다.

## 남은 한계

- KDC가 없거나 `8xx` 문학 번호가 아닌 74권은 기존 태그·소개 판단을 사용한다. 특히 55권은 정보나루에서 KDC를 받지 못했으며 재조회에서도 채워지지 않았다.
- KDC `813`은 서지 분류 근거다. 소설 작품, 선집, 해설이 섞인 책을 구별하는 근거로 단독 사용하지 않는다. 책의 형식·장르 필터와 코퍼스 검수는 계속 필요하다.
- 검색 상위 후보에 들지 못한 책은 이 변경만으로 최종 추천에 나타나지 않는다.
