# 기존 사서추천 자료에서 추가할 수 있는 갈피 판본

2026년 11월 26일 기준, 추천자료 2,504행에서 로컬 검증 DB 125권과 겹치지 않고 단일 ISBN과 한국어 소개 후보가 함께 있는 **505권**을 찾았다. 어린이·청소년은 2007년 1월부터 2025년 8월까지 CSV 전체, 성인은 기존 검토 범위인 2026년 2·4·6·8·10월 보도자료 본문 전체를 조사했다. 책이나 소개를 모델에 보내거나 운영 DB에 등록하는 작업은 별도로 진행한다.

어린이·청소년 후보를 추천 대상별로 세면 유아 149권, 초등고학년 114권, 초등저학년 167권, 청소년 72권이다. 분야는 원자료 표기를 따랐다. 문학에는 작품을 해설하는 책도 포함되며, 순수과학과 자연과학은 원자료에서 구분한다.

성인 신규 후보는 『검은 해바라기』, 『불필요한 여자』, 『넥스트 씽킹』이다. 성인 사서추천 전체 아카이브의 규모는 이번 집계 범위 밖이다.

## 집계 기준과 이용 범위

- 어린이·청소년 사서추천 CSV는 이용허락범위 제한 없음으로 공개돼 있다. ISBN 칸이 비어 있거나 복수 번호가 있는 경우가 많아, 기존에 판본을 검토한 기록을 재사용하고 나머지는 충남 소장자료와 성남 장서 파일 51개에 대조했다. 전체 서명과 저자 책임표시를 정규화해 맞추고 발행연도 또는 발행처도 일치하는 단일 ISBN만 골랐다. 복수 ISBN을 임의로 나누지 않았다. [추천글 원자료](https://www.data.go.kr/data/15151124/fileData.do) · [충남 소장자료](https://www.data.go.kr/data/15119625/fileData.do) · [성남 소장자료](https://www.data.go.kr/data/3071094/fileData.do)
- ISBN으로 두 소장목록을 역조회했을 때 정규화한 서명이 달라지면 보류했다. 『곱빼기로 땡큐 땡큐』와 『그래, 결심했어!』에는 같은 번호가 쓰였다. 부제가 빠진 『리보와 앤』처럼 표기 차이일 수 있는 사례도 보류에 들어간다. 소개 후보가 있고 역조회 단계에서 보류한 고유 번호는 450개다. 이를 신규 505권에 합산하지 않았다.
- 소개 후보는 기존 검토 기록 또는 사서추천글의 첫 완결 문장을 사용했다. 자동 선별에서는 서점·제공처·인용 표시 등을 먼저 확인하고, 따옴표나 마크업이 나오기 전의 완결 문장만 65~480자로 골랐다. 길이는 이번 조사에서 둔 기준이다. 짧아서 빠진 글과 판권이 불명확한 글은 같은 보류 건수에 들어간다. 후보를 실제 등록할 때는 해당 문장이 책 선택에 도움이 되는지 확인하고 원자료의 출처를 함께 표시한다.
- 국립중앙도서관 추천 API에는 제3자 권리가 포함된다고 표시돼 있다. 성인 소개 후보는 공공누리 제1유형이 표시된 보도자료에서 해당 책 한 권을 설명하는 기관 문단만 셌다. 원본 보도자료 URL, 기관명과 이용조건을 표시하는 기존 필드 정책을 적용할 수 있는 범위다. [추천 API의 이용조건](https://www.data.go.kr/data/15064371/openapi.do) · [공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do) · [기존 필드별 정책](../acquisition-20261123/policies.sql)

[행별 조사표](inventory.tsv)에는 출처별 원본 식별자, 분야, 독자층, ISBN 또는 보류 사유, 소개 근거와 최종 상태를 기록했다. 어린이·청소년의 원본 식별자는 헤더를 1행으로 계산한 CSV 레코드 번호다. 소장자료 근거는 공공데이터셋 ID와 등록번호, 성인 서지는 국가서지 제어번호로 확인할 수 있다. 새로 선별한 어린이·청소년 추천글에는 도입부의 UTF-8 SHA-256을 남겼다.
