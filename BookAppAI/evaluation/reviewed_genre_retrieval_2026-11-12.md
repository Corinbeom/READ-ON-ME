# 검토 승인 도서의 장르 검색 노출 — 2026-11-12

## 원인

`SF 소설 추천`에서 검토 승인한 『당신 인생의 이야기』(ISBN `9788956057842`)는 임베딩 전체 순위 145위, 유사도 0.4894였다. 기존 검색은 임베딩 상위 30권과 키워드·태그 일치 상위 20권을 가져왔다. 이 책에는 정확한 `SF` 키워드·태그가 있었지만 두 경로의 상한 밖에 있어 최초 후보 30권은 전부 `LEGACY`였다. 책 소개는 SF 소설집임을 명시하며 기존 장르 필터도 통과했다. 따라서 장르 판정 실패가 아니라 **제한된 후보 수 안에서 높은 임베딩 점수의 기존 책이 슬롯을 차지한 문제**다.

## 변경

- 명시적인 좁은 장르(`SF`, 판타지, 로맨스, 스릴러, 미스터리, 디스토피아) 요청에만, 관리자 승인 기록(`CURATED_SEED`, `ACTIVE`, 분류 버전 `:reviewed`)과 **장르 키워드·태그의 정확한 일치**가 있는 책을 별도 경로에서 최대 5권 찾는다. 저자 직접 검색에는 적용하지 않는다.
- 기존 유사도 하한과 장르·형식 필터를 그대로 적용한다. 상태만으로 검색 점수를 올리지 않는다.
- Gemini 입력 10권 중 최대 2자리를 이러한 검토 승인 도서에 배정한다. 기존 상위 8권은 유지하고, 오류 시 대체 결과 순서는 바꾸지 않는다. `한국소설`처럼 넓은 요청에는 이 배정을 적용하지 않는다.

## 로컬 실기동 결과

| 질의 | 검토 승인 도서의 검색 후보 → Gemini 입력 → 최종 결과 | 관찰 |
| --- | --- | --- |
| `SF 소설 추천` | 1 → 1 → 1 | 재실행에서 Gemini가 『당신 인생의 이야기』를 근거가 확인된 이유와 함께 선택. 기존 기록은 검색 후보 0권. |
| `우주를 다룬 SF 소설 추천` | 1 → 1 → 0 | 모델은 더 직접적인 다른 책을 선택. 입력 기회는 확보되지만 최종 노출을 강제하지 않는다. |
| `판타지 소설을 읽고 싶어` | 0 → 0 → 0 | 해당 장르의 검토 승인 도서가 없어 새 경로에서 추가된 책이 없다. |
| `한국소설 추천` | 적용 대상 아님 | 기존 넓은 장르 경로로 동작. |

첫 `SF 소설 추천` 호출에서는 Gemini가 HTTP 503을 반환해 기존 순서의 대체 결과가 나왔다. 같은 질의를 한 번 재실행하자 `MODEL` 결과가 나왔다. 첫 네 질의 실행 기록은 `/tmp/readonme-reviewed-retrieval-2026-11-12.json`, 재실행은 `/tmp/readonme-reviewed-retrieval-sf-retry-2026-11-12.json`에 있다.

이번 검증은 로컬 DB의 승인 도서가 한 권인 작은 표본이다. 장르별 승인 도서가 늘어나면 검색 후보 구성의 효과와 상위 결과의 적합도를 다시 사람 평가로 확인해야 한다. 모델 오류 때 승인 도서가 대체 결과 상위 5권에 들지는 않았다.
