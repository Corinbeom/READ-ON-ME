# 추천 결과 품질 보완 — 2026-11-11

## 재현과 원인

로컬 Spring AI 작업을 통해 `SF 소설 추천`이 `SUCCEEDED`이면서 0권을 반환하는 현상을 재현했다. 당시 FastAPI 검색에는 벡터 30권·키워드 20권·제목 20권이 들어왔고, 병합 30권 중 7권이 후보 검사를 통과했다. Gemini 호출은 12초 시간 초과였으며, 기존 대체 경로의 `infer_book_form`은 7권을 모두 `UNKNOWN`으로 판정해 0권을 반환했다. 검색 후보가 없었던 문제가 아니다. 해당 작업 ID는 `06fa9905-2caa-403d-acdc-6955fe8be638`이다.

일반 `소설 추천해줘`는 별도의 Gemini 시간 초과 때 대체 결과 4권 중 학교용 선집 두 권을 일반 단행본보다 먼저 반환했다. 선집에는 실제 작품이 들어 있으므로 코퍼스에서 제외할 근거로 보지 않았다. 제목과 소개에 학교 대상·선집 형식이 모두 드러나는 경우에만 일반 소설 요청에서 순위를 낮추기로 했다.

## 변경

- 좁은 장르를 명시한 이야기형 요청은 Gemini 장애 시에도 후보의 장르·형식 근거를 다시 검증해 `UNKNOWN` 형식의 적합한 책을 대체 결과에 포함한다. 명백한 가이드와 실용서는 제외한다. Gemini가 정상 응답으로 빈 배열을 선택하면 그대로 유지한다.
- 일반 소설 요청에서는 학교용 선집을 후보 목록과 최종 결과의 뒤로 안정적으로 배치한다. 사용자가 선집·모음집·중고생용 책을 직접 요청하면 이 우선순위를 적용하지 않는다. 코퍼스 상태는 변경하지 않았다.
- Spring 작업 ID를 검색·재정렬·대체 결과 로그에 공통으로 남긴다. Alembic 실행이 기존 앱 로거를 비활성화하지 않도록 해 실제 서버 로그에서도 단계별 기록을 확인했다.
