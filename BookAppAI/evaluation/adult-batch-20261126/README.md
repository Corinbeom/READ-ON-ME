# 성인 사서추천 35권을 추가한 갈피 검색 평가

국립중앙도서관 사서추천에서 확보한 한국어판 35권을 로컬 검증 DB에 추가했다. 제목·저자·소개 105개 필드는 앞선 조사에서 확인한 판본과 기관 보도자료를 사용했다. [판본과 출처](../librarian-pilot-20261126/adult-sources.md) · [입력 파일](../librarian-pilot-20261126/adult-fields.json)

같은 코드로 기존 141권과 새 176권을 비교했다. 성인 질문 8개는 출처에서 다루는 주제를 보고 실제 독자 상황으로 작성했다. 기존 독자 질문 4개는 새로 들어온 책과 비슷한 주제라도 독자가 요청한 용도에 맞는지, 기존에 나오던 책이 계속 나오는지 보기 위해 골랐다. 예를 들어 탐조 여행지를 찾는 질문과 공원에서 새 이름을 식별할 도감을 찾는 질문은 따로 판정했다. 가상 수상명·작가명 대조 2개도 같은 문장으로 실행했다. [질문과 판정 기준](questions.json)

기존 141권의 입력 버전·태그·벡터를 비교해 모두 일치하는지 확인했다. 추가한 35권의 현재 입력은 앞서 확보한 105개 필드와 일치했고, 각 판본에 태그와 벡터가 하나씩 생겼다. 색인 중 모델의 503 응답으로 재시도한 판본이 세 권 있었다. 색인 완료 후 같은 파일을 다시 등록하고 35권을 재색인하는 검사에서는 모델 호출이 0건이었고 코퍼스 버전도 같았다.

## 같은 질문의 첫 추천

| 독자가 찾은 책 | 141권 | 176권 |
|---|---|---|
| 계절별로 찾아갈 국내 탐조 여행지 | 빈 결과 | 우리나라 탐조지 100 |
| 일을 끝내기 힘들게 만드는 완벽주의 | 빈 결과 | 완벽이라는 중독 |
| 신분에 따라 달랐던 조선의 모자 | 빈 결과 | 모자의 나라 조선 |
| 전시디자이너가 들려주는 전시 기획 사례 | 빈 결과 | 전시디자인, 미술의 발견 |
| 가족이 같은 일을 다르게 기억하는 이유 | 가리방으로 기억하는 열두 살 소년의 4·3 | 가리방으로 기억하는 열두 살 소년의 4·3 |
| 영생을 추구하는 사회의 갈등을 그린 소설 | 빈 결과 | 텔로미어 |
| 당시 소설을 통해 보는 일제강점기 서울의 음식 | 빈 결과 | 빈 결과 |
| 기후위기와 경제를 함께 다루는 입문서 | 빈 결과 | 기후를 위한 경제학 |

주제 질문의 첫 책 적합은 **0/8에서 6/8**로 늘었다. 제주 4·3 증언집은 가족마다 다르게 기억하는 장면을 보여 주지만 기억 오류의 원인을 설명하지 않아 두 번 모두 부적합으로 판정했다.

기존 독자 질문 4개에서는 서양화 감상, 첫 월급 관리, 이주 당사자의 경험 등 세 질문이 전후 모두 적합한 첫 책을 반환했다. 공원에서 쓸 새 도감은 141권에서 큰 판형(29cm)의 『새 도감』이 나왔고 176권에서는 빈 결과였다. 전자의 도감은 새를 식별하는 데 도움이 되지만 소개가 집에서 관찰 뒤 펼쳐 보기를 권해, 두 결과 모두 휴대용 도감을 요청한 기준에는 미달했다. 가상 수상명·작가명 대조는 전후 모두 2/2 정상 빈 결과였다.

두 실패 질문은 검색 단계를 나누어 확인했다.

- 기억 오류를 설명하는 『도둑맞은 뇌』는 벡터 검색 1위로 최종 정렬 후보에 들어갔다. 원래 문장을 한 번 더 검색해도 모델이 4·3 증언집을 골랐다. “기억의 오류를 연구한 과학자가 쓴 책이 있을까요?”로 물으면 『도둑맞은 뇌』가 나왔다.
- 경성 음식문화를 다룬 『경성 맛집 산책』도 전체 벡터를 비교하면 1위였다. 하지만 “당시의 소설”에서 ‘당시’를 저자, ‘소설’을 요청 형식으로 추출해 최종 정렬에 도달한 후보가 0권이었다. “경성의 음식문화를 일제강점기 문학 작품으로 살펴보는 역사책”으로 물으면 해당 책이 나왔다.

표현을 바꿔 재현한 결과는 8개 원문 질문의 점수에서 제외했다. [질문별 전체 결과와 검색 단계 진단](evaluation.json)

## 기존 공개 기준과 상세 화면용 데이터

| 기준 | 141권 1·2차 | 176권 1차 | 176권 2차 |
|---|---|---:|---:|
| 첫 책 적합 (13/18 이상) | 18/18, 17/18 | 18/18 | 18/18 |
| 적합한 책 한 권 이상 (15/18 이상) | 18/18, 18/18 | 18/18 | 18/18 |
| 가상 작가·수상명에 정상 빈 결과 (2/2) | 2/2, 2/2 | 2/2 | 2/2 |

별도 번아웃 질문에는 두 번 모두 직장인의 번아웃 경험을 담은 『더는 태울 수 없어서』가 먼저 나왔다. 141권에서 첫 책이던 『내가 뭘 했다고 번아웃일까요』는 이번 두 결과에서 빠져, 경험담과 소설을 고를 수 있었지만 구체적인 회복 연습을 다루는 책은 보이지 않았다. 이 사례는 공개 기준 18문항 점수에 합산하지 않는다.

새 버전의 평가를 한 차례만 기록했을 때 로컬 API는 HTTP 503과 `AI_SEARCH_MAINTENANCE`를 반환했다. 두 차례 통과한 뒤 35권 전체를 상세 API로 조회해 ISBN·제목·저자·소개가 입력 파일과 정확히 일치하는지 확인했다. 같은 API의 검색 경로에서 탐조 여행지, 조선 모자, 영생 소설 질문을 다시 실행해 HTTP 200과 같은 첫 책을 확인했다. AI 서버 자동 테스트는 239개가 통과했다. 이번 검증은 로컬 DB 복제본에서 진행했다.

## 같은 판본으로 검증하기

아래 명령은 141권을 갖춘 검증 DB의 복제본에서 `BookAppAI` 디렉터리를 기준으로 실행한다. 색인에는 기존 서비스와 같은 태깅·임베딩 모델을 사용한다. 모델의 추천 순서는 실행마다 달라질 수 있으므로 질문 문장과 판정 기준을 고정해 비교한다.

```sh
manifest=evaluation/librarian-pilot-20261126/adult-fields.json
questions=evaluation/adult-batch-20261126/questions.json
python -m tools.evaluate_reviewed before.jsonl --questions "$questions"
python -m tools.reviewed_corpus import "$manifest" --new-only
python -m tools.reviewed_corpus index $(jq -r '.[] | select(.field=="title") | .isbn' "$manifest")
python -m tools.evaluate_reviewed after.jsonl --questions "$questions"
python -m tools.evaluate_reviewed release-run-1.jsonl
python -m tools.evaluate_reviewed release-run-2.jsonl
```

## 남은 후보

이번 35권 다음에 남는 후보는 489권이다. 기존 조사표의 어린이·청소년 486권은 CSV 원본과 판본·발췌문 해시를 대조해 제목·저자·소개 1,458개 필드를 다시 생성할 수 있었다. 유아 145권, 초등 저학년 163권, 초등 고학년 110권, 청소년 68권이다. 나머지 3권은 앞선 조사에서 찾은 2026년 성인 추천도서다. 이 489권은 색인 대기 수량이다.
