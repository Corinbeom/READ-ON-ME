# 코퍼스 수집 검증 — 2026-11-11

## 방법

- 카카오 도서 API의 첫 페이지에서 검색어 7개(`세계문학전집`, `한국소설`, `자기계발서`, `습관`, `에세이`, `과학교양서`, `역사교양`)별 1·2·4·6위 도서, 총 28권을 고정 표본으로 뽑았다.
- 제목과 카카오 소개만 보고 일반 독자용 단행본인지, 해당 배치 키워드에 맞는지 임시 판정했다. 판단이 어려운 4권은 `null`로 남겼다. 라벨은 [`corpus_admission_cases.json`](corpus_admission_cases.json)에 있다.
- DB를 변경하지 않는 별도 프로세스에서 신규 파이프라인과 같은 ISBN·사전 검사, 키워드 임베딩 유사도 기준(`0.45`), Gemini 분류·근거 문구 검증을 적용했다. 기존 ISBN 중복 검사는 제외하여 이전 데이터도 품질 관점에서 다시 보았다.
- 이 표본은 검색 결과의 앞부분을 의도적으로 골랐고 라벨도 카카오 소개에 근거한 예비 판단이다. 아래 수치는 전체 코퍼스의 정확도나 재현율 추정치가 아니다.

## API 호출 제한

첫 평가에서 연속 Gemini 분류 중 HTTP `503` 1건과 `429` 1건이 발생했다. 이후 6건은 로컬 쿨다운 때문에 호출 없이 미판정으로 기록됐다. 호출 간격을 두고 다시 실행하자 미판정 8건이 모두 해결됐다.

이에 따라 분류 호출 사이의 기본 최소 간격을 6초로 설정하고, 코퍼스 작업의 `429`는 간격을 늘려 계속 재시도하도록 수정했다. 이 조치가 장시간·다중 프로세스 운용에서 호출 제한을 완전히 방지하는지는 아직 검증하지 않았다.

## 후속 검증 우선순위

1. 책의 분류 라벨을 정규화된 상위 장르와 연결해 배치 키워드 적합성을 다시 확인한다. 기존의 정확한 문자열 일치 규칙은 이 표본의 정상 도서도 다수 제외하므로 그대로 복구하면 안 된다.
2. 기존 `LEGACY` 코퍼스의 명확한 세트·교재·정기간행물 후보를 사람 검토 후 소량씩 제외한다.
3. 소개가 짧아 `HOLD`가 된 책의 메타데이터 보강 경로를 마련한다. `한국소설` 첫 페이지 20권 중 12권이 소개 길이 기준에 걸렸다.
4. 장르·시기·출판사별 표본과 독립적인 사람 라벨을 늘린 뒤 실제 추천 결과에서 오추천과 누락을 재측정한다.
