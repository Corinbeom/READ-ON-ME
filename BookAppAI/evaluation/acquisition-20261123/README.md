# 갈피 추천도서 100권 확보 실험

2026년 11월 23일에 서로 다른 독서 목적에서 책 100권을 선정했다. 그중 40권은 한국어 소개를 새로 쓰지 않고 확보했다. 기존 73권을 복제한 로컬 검증 DB에 이 자료를 등록해 113권으로 검색을 평가했다.

| 후보 출처 | 조사 | 판본·소개 모두 확보 | ISBN을 확인했고 소개 검토 필요 | 판본 검토 필요 |
|---|---:|---:|---:|---:|
| 국립중앙도서관 사서추천 | 30 | 14 | 16 | 0 |
| 국립어린이청소년도서관 사서추천 | 40 | 26 | 3 | 11 |
| 충남도서관 소장자료에서 고른 생활·사회 분야 | 30 | 0 | 30 | 0 |
| 합계 | 100 | 40 | 49 | 11 |

판본을 확인한 89권의 ISBN은 서로 달랐고 기존 73권과 겹치지 않았다. 판본을 보류한 11권 중 9권에는 이용 가능한 소개가 있다. 따라서 한국어 소개 확보율은 49/100이고, 실제 등록률은 40/100이다. 특정 분야와 자료원을 정해 고른 표본이므로 전체 도서의 확보율로 일반화할 수 없다. [후보별 ISBN·판정·원본 참조](candidates.json)

## 어떤 책을 골랐나

- 국립중앙도서관의 2026년 2·4·6·8·10월 추천자료에서 매월 문학 1권, 사회과학 2권, 인문과학 1권, 자연과학 2권씩 골랐다. 등록한 14권의 구성은 문학 2권, 사회과학 4권, 인문과학 3권, 자연과학 5권이다.
- 어린이·청소년은 문학, 자연과학, 생활·기술, 역사·사회, 예술에서 각 8권씩 골랐다. 등록한 26권은 각각 8·5·4·4·5권이다. 두 추천목록 모두 같은 부문의 후보에는 고정 문자열과 원본 식별자를 결합한 SHA-256 정렬을 적용했다.
- 이전 30개 독서 상황에서 보강할 대상으로 러닝, 스마트폰 기초, 가족 대화, 수납, 주택 임대차, 이주 경험을 정했다. 충남도서관 소장자료에서 각 5권씩 골랐다. 러닝 등 중의적인 검색어는 서명을 읽어 주제에 맞는 후보로 추렸다. 30권 모두 ISBN이 있었지만 대조한 추천자료에서 해당 판본의 소개를 확보하지 못했다.

## 판본과 본문 확인

국립중앙도서관은 추천도서 식별자에서 국가서지 제어번호로 이동해 개별 판본의 ISBN을 확인했다. 서명·저자명과 소개를 각각 기록했다. 소개에는 공공누리 제1유형을 표시한 월별 보도자료에서 한 책을 설명하는 문단을 사용했다. 기관명, 추천 월, 이용조건, 원문 링크를 본문에 포함했다. 향후 이용자에게 이 소개를 제공할 때도 출처와 원문 링크를 함께 표시해야 한다. [추천 서지](https://www.data.go.kr/data/15064371/openapi.do) · [10월 보도자료](https://www.nl.go.kr/NL/contents/N50603000000.do?schM=view&id=59351) · [공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do)

국립어린이청소년도서관 CSV에는 2,464행의 추천글이 있고 ISBN 칸에 값이 있는 행은 34개였다. 제목·저자와 발행연도 또는 발행처를 소장자료에 대조했다. 여러 ISBN이 나오거나 책임표시가 축약된 자료는 개별 서지를 추가로 확인했다. 예를 들어 『도서관을 훔친 아이』는 국회도서관 서지에서 세트 번호와 개별 권 번호를 구분할 수 있었다. 한국어 본문에는 공공데이터포털에 이용허락범위 제한 없음으로 등록된 추천글에서 발췌한 문장을 사용했다. 문장에 출처와 추천 연월을 붙였다. 원자료의 일부 띄어쓰기와 표기 오류가 남아 있다. [어린이·청소년 사서추천 원자료](https://www.data.go.kr/data/15151124/fileData.do) · [국회도서관 판본 예시](https://dl.nanet.go.kr/detail/MONO12024000002512)

소장목록은 판본 확인과 후보 발견에 사용했다. 후보의 `edition_evidence`에서 숫자로 시작하는 참조는 공공데이터포털 데이터 번호와 도서관 등록번호로 구성된다. `#row=N`은 헤더를 첫 레코드로 센 CSV 레코드 번호다. 검토한 CSV의 SHA-256은 `f4fb6ad3646cd4c6e309f63dceaa8cebfc06b5016c216674f892e56bda3681e3`이다. [성남시 소장자료](https://www.data.go.kr/data/3071094/fileData.do) · [충남도서관 소장자료](https://www.data.go.kr/data/15119625/fileData.do)

## 검증 환경에서 재사용

[필드 목록](fields.json)은 등록할 40권의 제목·저자·소개 120건만 담고 있다. 각 값에 제공처, 원문 참조, 확인일, 정책 버전이 연결되어 있다. [검토한 이용조건](policies.sql)을 검증 DB에 등록한 뒤 BookAppAI 디렉터리에서 기존 도구로 적용할 수 있다.

```sh
python -m tools.reviewed_corpus import evaluation/acquisition-20261123/fields.json --new-only
python -m tools.reviewed_corpus index $(jq -r '.[].isbn' evaluation/acquisition-20261123/fields.json | sort -u)
python -m tools.evaluate_reviewed --reader-scenarios results.jsonl
```

## 검색 전후 비교

기존 73권과 확장한 113권에 같은 독서 상황 30개를 한 번씩 질의했다. 각 결과의 상위 다섯 권을 기존 질문별 기준으로 판독했다. 모델 오류 또는 재시도 대기 중 대체 순위를 쓴 질문은 각각 18개와 12개였다. 한 번씩 실행한 수치에는 이 차이도 반영돼 있다. [질문별 추천 순서와 적합 판정](evaluation.json) · [질문과 평가 기준](../reviewed/reader-scenarios.json)

| 질문 30개 | 첫 책 적합 | 한 권 이상 적합 | 빈 결과 | 책은 나왔으나 적합한 책 없음 |
|---|---:|---:|---:|---:|
| 기존 73권 | 20 | 22 | 4 | 4 |
| 검증 113권 | 21 | 22 | 6 | 2 |

서양화 감상 입문 질문에서 새로 넣은 『꽃 아주머니와 비밀의 방』이 첫 번째로 나왔다. 청소년 기후 토론 질문에는 『(청소년을 위한) 환경 교과서』가 두 번째로 나왔다. 베란다 식물 질문에는 기존 소장 자료인 『Plantopedia』가 다시 검색됐고, 반대로 한국 동물 그림책 질문은 이전의 하위 적합 결과를 잃었다. 여섯 생활·사회 분야에서는 적합한 응답을 얻지 못했다. 예컨대 러닝 입문 요청에는 달리기 훈련을 다루지 않는 일반 습관서가 나왔다.

별도로 새 책의 주제에 맞춘 예시 두 건도 질의했다. 가족을 잃고 남은 사람들의 소설에는 『애니가 남긴 것』, 택배가 바꾼 도시와 노동에는 『호모 딜리버리쿠스』가 각각 첫 번째였다. 이 두 건은 30개 질문의 점수에서 제외했다.

DB와 입력 파일을 대조해 신규 120개 필드의 값·정책·원문 참조가 일치하고 40권 모두에 태그와 임베딩이 생성됐음을 확인했다. 기존 필드와 기존 태그·임베딩의 결과 해시도 대조했다. 이번 반영 범위는 로컬 검증 DB다.
