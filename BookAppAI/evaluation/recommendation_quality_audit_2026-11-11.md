# 대표 질의 추천 품질 점검 — 2026-11-11

## 방법과 기준선

로컬 FastAPI에 [`representative_queries.json`](representative_queries.json)의 12개 질의를 6초 간격으로 보냈다. 평가 도구는 요청 ID와 응답 시간을 결과에 남기고 각 질의 직후 파일을 갱신한다. 검색·재정렬 로그는 같은 요청 ID로 대조했다. 변경 전 원본은 `/tmp/readonme-quality-audit-before-20261111.json`, 변경 후 원본은 `/tmp/readonme-quality-audit-after-20261111.json`이다. 두 파일은 로컬에만 있다.

| 항목 | 변경 전 | 교육과정 필터 적용 후 |
| --- | ---: | ---: |
| 질의 | 12 | 12 |
| 반환 도서 | 34 | 42 |
| 빈 응답 | 1 | 0 |
| Gemini / 대체 결과 도서 | 22 / 12 | 13 / 29 |
| 확인된 근거가 있는 추천 이유 / 이유 없음 | 16 / 18 | 12 / 30 |
| 금지 제목·명확한 이야기형 실용서 위반 | 0 | 0 |

두 실행의 Gemini 장애 횟수가 달라 전체 도서 수·빈 응답·이유 수를 개선 효과로 비교할 수 없다. 추천 이유가 없는 책에는 장애 시 대체 결과가 포함된다. 책 전문가의 장르 판정이나 주관적 관련성 점수는 입력하지 않았다.

## 확인한 문제와 조치

1. `재테크 기초 책 추천`의 대체 결과 5권에 『경제수학, 위기의 편의점을 살려라!』가 포함됐다. 소개에는 중학교 교과과정과 고교학점제 준비가 명시돼 있다. 일반 독자의 입문 요청에서는 이런 **명시적 학교 교육과정** 신호를 가진 책을 Gemini 후보와 대체 결과에서 제외한다. `10대 재테크 기초`처럼 청소년 독자를 지정한 요청에는 이 필터를 적용하지 않는다. 재평가에서는 같은 대체 경로의 앞선 4권을 유지하고 이 책만 빠졌다.
2. 재평가의 `판타지 소설을 읽고 싶어` 대체 결과에 작품이 아닌 판타지 문학의 개념·작품세계를 설명하는 『판타지』가 포함됐다. 세부 장르 대체 경로에서 형식이 `UNKNOWN`인 책에는 장르 일치 외에 소설·단편·서사·세계관·캐릭터 등 **작품 근거**도 요구한다. 실제 코퍼스의 5권을 대상으로 Gemini 없이 대체 경로를 실행하자 『판타지』만 빠지고 『룬의 아이들 블러디드 6』을 포함한 4권이 유지됐다. 같은 방식으로 SF 결과 5권은 유지됐다.

전체 FastAPI 테스트 148개가 통과했다. 이번 작업은 책을 삭제하거나 코퍼스 상태를 바꾸지 않았다.

## 남은 문제

- 조지 오웰 유사 분위기 요청은 첫 실행에서 Gemini `503` 이후 주제 검사를 통과한 3권이 모두 형식 불명으로 분류돼 0권이었다. 두 번째 실행은 Gemini가 정상 응답해 『멋진 신세계』와 『화씨 451』을 반환했다. 다른 작가의 작품을 억지로 채우지 않으면서 장애 시 대체 결과를 제공할 근거가 있는지 별도 검토가 필요하다.
- 『한 번뿐인 인생은 어떻게 살아야 하는가』 같은 에세이형 이야기와 학교용 문학 선집은 독자 요청에 따라 적합성이 달라져 이번에 일괄 제외하지 않았다. 『탈무드의 두 번째 비밀』처럼 이야기와 학습 요소가 혼합된 책도 추가 검토 대상으로 남긴다.
- 이 평가는 로컬 코퍼스와 두 번의 실제 API 호출 결과에만 해당한다. Gemini 응답 변동이 있으므로 결과 권수만으로 추천 관련성 향상을 주장하지 않는다.
