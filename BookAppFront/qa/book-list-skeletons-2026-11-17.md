## 실제 브라우저 검증

로컬 Expo `localhost:8082` → 검증용 프록시 `localhost:18081` → 실제 Spring `localhost:8080` 경로를 사용. 정상 데이터는 실제 API 응답이며 프록시에서 지연(2.5~6초)과 503만 통제하여 주입. 운영 서버 설정·데이터를 변경하거나 AI 검색 작업을 제출하지 않음.

- 홈: 503 시 스켈레톤 종료·인라인 재시도, 전역 중복 알림 없음. 3.5초 응답에서 스켈레톤 표시, 236px 예약 높이와 첫 표지 y=422를 실제 결과에서도 유지. 빠른 응답은 관측 중 스켈레톤의 시각적 노출 없음.
- 로그인 사용자의 홈: 인기 목록과 개인 추천의 스켈레톤 2개 및 연령대 조건 확인. 실제 두 단계 추천 조회 후 정상 전환.
- 검색: 2.5초 응답의 플레이스홀더 첫 표지 y=233과 실제 20권의 첫 표지 y=233 일치. 초기 검증의 4px 헤더 차이를 보정.
- 같은 검색어 갱신과 503 후에도 동일 이미지 DOM을 유지, 새 스켈레톤으로 덮지 않음. 실패 안내와 재시도 확인.
- 다른 검색어 조회 시 이전 책 링크 0개 및 새 스켈레톤 확인. 실제 0건 검색은 빈 결과 안내로 전환하고 스켈레톤 종료.
- 서재: 새 로컬 빈 QA 계정의 최초 스켈레톤 → 빈 서재 전환. 기존 테스트 계정의 통계·3개 선반 전환 확인. 첫 표지 y=293을 유지.
- 서재 재조회 및 503에도 같은 표지 DOM을 유지하며 스켈레톤 미표시·재시도 확인. 책 상태는 변경하지 않음.
- 탭 이탈 후 불투명도 0, 0.5초간 애니메이션 스타일 변경 0회 확인. 빠른 재진입 후에도 노출 없이 실제 빈 결과로 전환.
- 320 / 390 / 1280px × 3가지 레이아웃 9조합에서 예약 높이 유지, 문서 가로 넘침·플레이스홀더 링크·버튼 없음.
