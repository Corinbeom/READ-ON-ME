# 모바일 웹 베타 검증 (2026-11-15)

## 환경과 범위

- 브랜치: `feat/mobile-web-beta`, 기준 `main` 커밋 `04992f3`.
- 로컬 Expo 웹 `http://localhost:8081`, Spring `8080`, FastAPI `8000`, 기존 PostgreSQL·Redis.
- gstack browse의 실제 Chromium에서 390×844, 320×568, 1280×800 화면 크기를 확인했다. 실제 iOS Safari의 터치·소프트 키보드 동작을 검증한 것은 아니다.
- 기존 테스트 계정으로 실제 로그인과 API 요청을 수행했다. 새로운 회원·리뷰를 만들거나 기존 리뷰를 삭제하지 않았다.

## 실행한 흐름

| 흐름 | 결과 |
| --- | --- |
| 빈 로그인 입력 | 안내 대화상자 표시, 확인 후 닫힘 |
| 잘못된 비밀번호 | 서버의 로그인 거부 뒤 실패 안내 표시 |
| 정상 로그인 | API 200, 성공 대화상자의 확인 버튼을 누른 뒤 홈 진입 |
| AI 검색 | `SF 소설 추천해줘`를 실제 접수하고 5권 결과 확인 |
| 두 권 비교 | 『당신 인생의 이야기』와 『SF 세계에서 안전하게 살아가는 방법』 선택 후 비교 화면 진입 |
| 한 권 선택 | 『당신 인생의 이야기』를 골라 선택 완료 화면과 책 상세 진입 |
| 서재 저장 | `POST /api/library/47?status=TO_READ` 200, 새로고침 후 서재의 읽고 싶은 책 목록에서 해당 책 확인 |
| 로그아웃 취소 | 취소 후 인증된 서재 화면 유지 |
| 로그아웃 확인 | 확인 후 홈의 로그인·회원가입 버튼 복원 |
| 재로그인과 검색 복원 | 재로그인 후 최근 검색 작업 200 응답과 기존 5권 결과 복원, 최종 브라우저 콘솔 오류 없음 |
| 반응형 | 320px 헤더의 서비스명 줄바꿈 수정, PC에서 화면 폭 640px 제한 확인 |

테스트 계정의 『당신 인생의 이야기』 상태는 `TO_READ`로 저장했다. 핵심 검색 흐름은 로컬 실제 API로 확인했으며 목 응답을 사용하지 않았다.

## 발견한 문제와 수정

1. 네이티브 `Alert.alert` 호출이 브라우저에서 표시되지 않아 로그인 성공 뒤 이동하지 않았다. 일부 화면은 기존 웹 폴리필을 사용했지만 그 구현도 선택 없이 첫 동작을 실행했다. 웹용 대화상자를 공통화해 사용자가 누른 버튼의 동작만 실행하도록 바꿨다. 여러 선택과 알림 대기열, 취소 및 네이티브 위임을 Node 테스트로 검사한다.
2. 로그인 토큰이 콘솔에 기록돼 해당 로그를 제거했다.
3. PC에서 화면이 과하게 늘어나고, 320px 폭에서는 서비스명이 중간에 끊겼다. 웹에 최대 폭을 적용하고 헤더 줄 배치와 로고 크기를 조정했다.
4. API 주소가 개발 호스트의 HTTP 주소로 고정돼 있었다. 공개 `EXPO_PUBLIC_API_URL`을 우선 사용하고 배포 빌드에는 외부 HTTPS 주소를 요구한다. 사용하지 않는 직접 AI 서버 클라이언트도 제거했다.

## 자동 검사와 빌드

- `npm test`: 3개 통과.
- `npm run typecheck`, `npm run lint`: 통과.
- API 주소 없이 `npx expo export --platform web`: 의도한 설정 오류로 실패.
- `EXPO_PUBLIC_API_URL=https://api.example.invalid npx expo export --platform web --output-dir /tmp/readonme-web-beta-export`: 정적 경로 13개와 웹 번들 생성 성공. 이 주소는 빌드 검증용 예시이며 실제 API 연결을 검증한 주소가 아니다.

## 외부 베타 전 남은 작업

로컬 웹의 핵심 사용 흐름은 통과했다. 외부 베타에는 실제 HTTPS API·웹 호스팅, 해당 웹 주소의 CORS 허용, DB·Redis 외부 노출 제거와 AI 검색 접근 통제가 필요하다. 호스팅에서 책 상세 등 직접 URL 접속·새로고침도 확인해야 한다. 신규 가입의 실제 저장, 리뷰 수정·삭제, 모바일 Safari와 Android Chrome의 실제 키보드 동작은 이번 검증 범위 밖이다.
