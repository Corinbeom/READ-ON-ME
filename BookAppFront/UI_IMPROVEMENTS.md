# UI 개선 태스크

## 완료

- 공통 화면 폭·여백·타이포그래피·버튼·입력창 규격 정리
- 하단 메뉴의 전체 클릭 영역 확대, 아이콘·선택 상태·키보드 조작
- 홈·검색·서재 제목 시작점 통일
- 홈 AI 사서 영역과 상황별 예시 진입, 인증 전후 조건 유지

검증 기록: [공통 UI](qa/ui-consistency-2026-11-16.md), [홈 AI 사서](qa/home-ai-discovery-2026-11-16.md).

## 완료: 검색 시작 화면

- 최근 검색어를 기기 안에 저장하고 재검색·개별 삭제·전체 삭제 제공
- 제목·저자 검색과 취향 기반 AI 추천의 용도를 안내
- AI 사서 진입 버튼과 상황별 예시 연결
- 로딩·결과 없음·조회 실패를 구분하고 재시도 제공
- 자동완성이나 이전 검색의 늦은 응답이 최신 입력을 덮지 않도록 처리

검증 기록: [검색 시작 화면](qa/search-discovery-2026-11-16.md).

## 다음 작업: 서재

- 서재에 ‘읽는 중’과 ‘읽고 싶은 책’을 직접 노출
- 서재 저장 결과와 선택 상태를 즉시 안내
- 책 목록 스켈레톤·조회 실패 재시도 등 상태 표시 보완

## 보관한 아이디어: 플로팅 하단 네비게이션

사용자가 UI 개선 범위에 추가했으며 구현은 후속 작업으로 남긴다.

- 화면 좌우에 16~24px, 하단 안전 영역 위에 약 12px 여백
- 기존 테마의 카드 배경, 둥근 모서리, 얇은 테두리와 약한 그림자
- 현재의 넓은 클릭 영역·선택 표시·키보드 포커스 유지
- 넓은 화면에서는 최대 폭을 제한해 가운데 배치
- 콘텐츠 하단에 메뉴 높이와 간격을 반영해 마지막 책·버튼을 가리지 않게 배치
- 실제 모바일 브라우저의 주소창·키보드·안전 영역과 함께 검증

구체적인 크기와 모서리 값은 착수 시 현재 디자인과 화면별 실측을 기준으로 확정한다.
