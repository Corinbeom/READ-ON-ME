# UI 개선 태스크

## 완료

- 공통 화면 폭·여백·타이포그래피·버튼·입력창 규격 정리
- 하단 메뉴의 전체 클릭 영역 확대, 아이콘·선택 상태·키보드 조작
- 홈·검색·서재 제목 시작점 통일
- 홈 AI 사서 영역과 상황별 예시 진입, 인증 전후 조건 유지

검증 기록: [공통 UI](qa/ui-consistency-2026-11-16.md), [홈 AI 사서](qa/home-ai-discovery-2026-11-16.md).

## 완료: 검색 시작 화면

- 최근 검색어를 기기 안에 저장하고 재검색·개별 삭제·전체 삭제 제공
- 제목·저자 검색과 취향 기반 AI 추천의 용도를 안내
- AI 사서 진입 버튼과 상황별 예시 연결
- 로딩·결과 없음·조회 실패를 구분하고 재시도 제공
- 자동완성이나 이전 검색의 늦은 응답이 최신 입력을 덮지 않도록 처리

검증 기록: [검색 시작 화면](qa/search-discovery-2026-11-16.md).

## 완료: 서재의 책 목록과 빈 화면

- 읽는 중·읽고 싶은 책·완독한 책을 표지와 함께 직접 노출
- 분류별 최대 6권 미리보기, 전체 목록과 책 상세 연결
- 빈 서재의 검색·AI 사서 진입, 로그인 후 서재 복귀
- 책·리뷰·독서 키워드를 독립적으로 조회하고 오류별 재시도 제공
- 상세에서 돌아올 때 기존 책을 유지하면서 목록 갱신

검증 기록: [서재 책 목록](qa/library-shelves-2026-11-17.md).

## 완료: 서재 저장 피드백

- 책 상세에 현재 상태와 선택 표시, 저장 중·완료 안내를 노출
- 초기 조회·저장 중 중복 요청 방지, 같은 상태 재선택 시 불필요한 저장 생략
- 실패 시 마지막 확인 상태 유지, 다시 저장·서버 상태 확인 제공
- 저장된 책에서 ‘서재 보기’로 이동

검증 기록: [서재 저장 피드백](qa/library-save-feedback-2026-11-17.md).

## 완료: 플로팅 하단 네비게이션

- 좌우 최소 16px, 하단 안전 영역 위 12px 여백
- 테마별 카드 배경·20px 모서리·얇은 테두리·약한 그림자
- 각 탭의 64px 클릭 영역과 선택·키보드 포커스 표시 유지
- 넓은 화면은 최대 480px, 가운데 배치
- 메뉴 공간을 레이아웃에서 확보하여 마지막 책·버튼의 스크롤 접근 유지

검증 기록: [플로팅 하단 메뉴](qa/floating-tabs-2026-11-17.md). 실물 기기의 가상 키보드와 네이티브 앱 확인은 후속 검증으로 남긴다.
